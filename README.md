# SmartCent

SmartCent is a modern **Android application** built with Kotlin that helps users manage expenses, track budgets, and stay on top of their financial goals. It combines clean UI design with smart notifications to make personal finance simple and engaging.

##  Features

### Core Features
- **Expense Tracking**: Add, edit, and categorize daily expenses.
- **Budget Management**: Set monthly budgets and monitor progress in real time.
- **Dashboard Overview**: Visualize spending trends with charts and summaries.
- **Profile System**: Personalize financial goals and manage user details.

### Additional Features
- **Smart Notifications**: Alerts for budget limits, achievements, and reminders.
- **Achievements & Rewards**: Gamified milestones to encourage saving habits.
- **Contextual Reminders**: Notifications tied to dashboard and profile activity.


## Tech Stack
- **Language**: Kotlin  
- **Framework**: Android SDK  
- **UI**: XML layouts with Material Design components  
- **Database**: Room / SQLite  
- **Version Control**: GitHub with frequent descriptive commits
